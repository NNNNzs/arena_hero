# Arena Hero 战术发展时间轴与阶段演进指南

本文档描述 Agent 从开局出生、初期防线、中期经济扩张到后期决战的**完整生命周期阶段、触发门槛与战术行为**。

---

## 阶段全景时间轴

```
[ Phase 0: 探索与出生评估 ] (Tick 1 ~ 20)
  ├── 双工起步，探测 12 格内矿脉
  └── 荒漠判定 ──(无矿)──> 核心自毁 (Fast Reroll)
            └──(有矿)──> 进入 Phase 1
                             ↓
[ Phase 1: 初期保命与防线建立 ] (人口 3 ~ 5)
  ├── 严格锁定: 2 Worker -> 2 Vanguard -> 1 Ranger
  └── 战术: CoreGuard 近卫站位 (1~2格)，防开局偷家
                             ↓
[ Phase 2: 中期经济与护送扩张 ] (防线成型: 先锋>=2 & 游侠>=1)
  ├── 经济跃升: 工人快速扩充至 5 Worker (mid_workers)
  └── 战术: 多路护送采矿 + 环形巡逻 (5~8格) + 游猎控图 (7~10格)
                             ↓
[ Phase 3: 集团军暴兵与战备蓄水 ] (人口 6 ~ 40)
  ├── 终极编制: 12 Worker / 12 Vanguard / 16 Ranger
  └── 战备: 留存 40 资源蓄水池，抵御战损与突发火线
                             ↓
[ Phase 4: 战役决战与信标主宰 ] (动态触发)
  ├── ATTACK: 发现敌核心 + 战力>=3 -> 集火推进
  ├── BEACON: 控盘争夺信标 -> 护盾上限扩充至 10
  └── 重生清零: 核心被毁 -> 自动清零状态，回到 Phase 0
```

---

## 阶段细则与决策条件

### 1. Phase 0：出生评估与极速刷矿（Tick 1 ~ 20）

* **目标**：杜绝“荒漠出生点”导致开局漫长逛街暴毙。
* **准入条件**：开局阶段（`context.workers <= 2` 且零战斗单位）。
* **行为**：
  - 核心自带 5 资源，立即孵化第 1 个工人（维持 2 工人开局）。
  - 双工人分向探索，重点搜索距 Core **12 格**（`spawn_eval_mine_max_dist`）内的可用矿脉。
* **极速自毁机制（Fast Reroll）**：
  - 若第 20 Tick（`spawn_eval_max_ticks`）仍未在 12 格内探明任何矿点，Core 判定该点为资源荒漠，自动触发 `ActionKind.SELF_DESTRUCT` 自毁刷新出生点。

---

### 2. Phase 1：双工起步与初级防线（人口 3 ~ 5）

* **目标**：零多余开销，快速攒资源建立 3 兵种基础防御环。
* **准入条件**：已发现近身矿脉，进入正常采集。
* **生产顺序（严格串行）**：
  1. `Worker`：补齐至 **2 个**（`early_workers = 2`）
  2. `Vanguard`：造满 **2 个**（`early_vanguards = 2`）
  3. `Ranger`：造满 **1 个**（`early_rangers = 1`）
* **站位与战术**：
  - 战斗单位分配 `core_guard`（近卫）角色，贴身环绕 Core 1~2 格防御。
  - 保留 5 资源底线，Core 自愈与修盾优先级高于生产。
  - 此阶段严禁多造第 3 个工兵，避免经济过载导致防线空虚。

---

### 3. Phase 2：中期经济与护卫扩张（初级防线达标）

* **目标**：防线稳固后快速打通多路采矿，经济供血翻倍。
* **准入条件**：`len(vanguards) >= 2` 且 `len(rangers) >= 1`（和平期）。
* **生产调整**：
  - 生产队列立即插队 **`Worker` 补齐至 5 个**（`mid_workers = 5`）。
  - 不受和平期 40 储备金阻拦，以 5 资源极低成本连续孵化。
* **战术协同与分工**：
  - **Worker**：展开东、南、西、北 4 扇区独立采矿；短时丢视野享有 **4 Tick 寻路宽限**（`continue_locked_resource_route`）。
  - **Vanguard**：
    - 保留 2 名 `core_guard` 近卫守家。
    - 其余分配 `patrol`（环形巡逻，距 Core 5~8 格，每 6 Tick 顺时针轮换）或 `recon_squad_vanguard_screen`（采矿前哨屏卫）。
  - **Ranger**：
    - 保留 1 名近卫。
    - 其余分配 `hunter`（前沿 7~10 格散开游猎控图）或 `recon_squad_ranger_flank`（侧翼火力掩护）。

---

### 4. Phase 3：集团军暴兵与战备蓄水（人口 6 ~ 40）

* **目标**：打造 40 人口上限集团军，建立战备蓄水池。
* **生产机制（最大缺口动态均衡）**：
  - 成熟期目标配置：`mature_workers: 12` / `mature_vanguards: 12` / `mature_rangers: 16`。
  - 当工人满 5 个后，核心按赤字最大的兵种动态补充。
* **战备蓄水池（Peacetime Buffer）**：
  - 维持 `peacetime_resource_buffer = 40`。
  - 在非交火期保留 40 资源余量，确保战时能秒补昂贵的后期重装兵种。
* **反隐身与脱困机动**：
  - 若连续受击且视野内无敌人（Streak $\ge 3$），Core 自动向安全空地迁移 1 格脱离敌方暗影盲狙火力。

---

### 5. Phase 4：战役决战与信标主宰（动态触发）

* **进攻战役（ATTACK 模式）**：
  - **触发**：发现敌方 Core + 己方战力 $\ge 3$ + 己方 Core 满血且护盾 $\ge 3$。
  - **战术**：全军集火推进，游侠寻找直线射击阵位，先锋向前突击卡位。
* **信标主宰（BEACON 模式）**：
  - **触发**：无近身威胁 + 战力充沛 + 信标落地。
  - **战术**：先锋前往拾取信标，己方护盾上限由 5 提升至 10。
* **战损自愈与清零（CORE_RESPAWNED）**：
  - 核心被摧毁后自动在新坐标重生；
  - 自动重置旧矿点、清空仇恨与单位任务、重置探索计数，重新从 **Phase 0** 循环。
